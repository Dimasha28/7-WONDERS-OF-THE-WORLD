# 🏛️ 7 Wonders of the World – Interactive Website

Welcome to the **7 Wonders of the World** project — a beautifully designed and informative website that showcases the seven most magnificent man-made structures across the globe.  
This project aims to educate and inspire visitors through visuals, descriptions, and historical facts about each wonder.

🌐 **Live Website:** [https://7-wonders-of-theworld.netlify.app/](https://7-wonders-of-theworld.netlify.app/)

---

## ✨ Overview

The **7 Wonders of the World Website** serves as an educational and visual journey through human achievement and architectural brilliance.  
Each section highlights one of the wonders with:
- Stunning images  
- Historical background  
- Location details  
- Fascinating facts  

This project was created to combine learning with interactive and aesthetic web design.

---

## 🚀 Features

### 🗺️ Content Highlights
- Detailed information about each of the 7 wonders  
- High-resolution images and cultural facts  
- Smooth scrolling navigation and transitions  
- Interactive layout with responsive design  

### 💻 Technical Features
- Fully responsive for all screen sizes (desktop, tablet, mobile)  
- Organized sections with modern UI and typography  
- Lightweight and fast-loading design  
- Hosted online via **Netlify**

### 🌎 Wonders Covered
1. Great Wall of China  
2. Petra (Jordan)  
3. Christ the Redeemer (Brazil)  
4. Machu Picchu (Peru)  
5. Chichen Itza (Mexico)  
6. Roman Colosseum (Italy)  
7. Taj Mahal (India)
